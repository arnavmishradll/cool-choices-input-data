# SOLWEIG input data for eleven cities

Findings on the DEM, DSM, land cover and tree canopy rasters prepared for SOLWEIG for Miami, Dallas, Houston, Los Angeles, New York City, San Francisco, Philadelphia and Tucson (NO-HEAT VIP, Cool Choices team).

Part 2 of the slideshow covers Seattle, Denver and Boulder, built with the same pipeline plus a tree canopy measured from the lidar (CDSM_lidar).

Site: https://arnavmishradll.github.io/cool-choices-input-data/

The page is a slideshow: use the arrows in the top right or the arrow keys. The source maps, 3D blocks (with a sun and shadow simulator) and validation sheets are interactive.

Data sources: USGS 3DEP, NOAA Digital Coast, UrbanWatch, NOAA C-CAP, ESA WorldCover, Meta / WRI canopy height v2, NAIP, Overture Maps, Microsoft building footprints. Landmark photos from Wikimedia Commons, credited on each validation sheet.
